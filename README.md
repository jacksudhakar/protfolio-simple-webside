# Personal Portfolio Website

## About the Project
A simple and attractive personal portfolio website created using HTML and basic CSS to showcase my introduction, skills, and contact details.

## Pages
- **Home (index.html):** Introduction, About Me, and Skills.
- **Contact (contact.html):** Contact information and contact form.

## Technologies Used
- HTML5
- CSS3

## Setup Instructions
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure `index.html`, `contact.html`, and CSS files are available.
4. Open `index.html` in your browser.(link)

## Usage
- Visit the Home page to learn about me.
- Click the Contact link to visit the Contact page.
- Explore my portfolio and web development skills.
